3D Parallax Menu

Полноэкранное меню с 3D-моделью на three.js и параллаксом при прокрутке на GSAP.

[Смотреть](https://alexbulanovgooddevelopment.github.io/code_3d-parallax-menu/)

![Превью](./preview.webp)

Запустите через локальный сервер (например, Live Server): ES-модули и 3D-модель не загружаются по file://. Библиотеки подключаются через CDN.
